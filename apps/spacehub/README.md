# Space Missions & Astronomy Hub

A Vue 3 + TypeScript + webpack 5 demo app for VBox native styling.

## Stack

- webpack 5 + vue-loader
- Vue 3 + Vue Router
- VBox (`@veebox/core`, `@veebox/vue`, `@veebox/unplugin` webpack adapter, `@veebox/volar`)
- Radix Vue primitives
- `@veebox/property-variance-authority` for component style variants
- Vitest + Testing Library

## Commands

```bash
pnpm install
pnpm -C apps/spacehub dev
pnpm -C apps/spacehub build
pnpm -C apps/spacehub type-check
pnpm -C apps/spacehub test
```
